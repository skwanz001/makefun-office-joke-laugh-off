Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) bounty on make.fun.

`main.py` (standard library only) writes one original one-line joke about office life to `/output/entry.txt`:

> The office plant died, so HR taped a photo of a plant to the wall and called it a wellness initiative.

Run it with `python3 main.py` (Python 3.13). The joke is 102 characters, one line — inside the 1–200 character gate.
